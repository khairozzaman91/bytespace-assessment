# ByteSpace

An online course platform landing page — frontend assessment project.

## Live Demo & Repository

- **Live Website:** [https://bytespace-assessment-iota.vercel.app/](https://bytespace-assessment-iota.vercel.app/)

## Tech Stack

- **React (Vite):** Frontend library for fast performance and component-based architecture.
- **Tailwind CSS:** For modern, responsive, and utility-first styling.
- **React Router:** For smooth Single Page Application (SPA) routing and page navigation.
- **lucide-react:** For modern vector icons across different UI components and sections.

## Completed Work & Features

**Navbar & Navigation**
- Brand logo + name
- Multi-page navigation links (Home, Courses, Creators)
- Sign In & Join Us buttons
- Interactive cart icon

**Brand Partners Section**
- Clean logo strip (Logoipsum × 5)

**Hero Section**
- Heading + subtext
- Interactive search box
- Background shape + hero image
- Floating cards (UI/UX Design, Learning Progress, Happy Students)
- Decorative shapes (desktop only)

**Categories & Course Catalog**
- Category tabs & explorer (Design, Development, IT, Music, etc.)
- Course grid with levels, ratings, and student counts
- Dynamic keyword search and 404 Not Found fallback view

**Explore Paths & Growth Sections**
- Explore learning paths for professional development
- Growth & stats section highlighting professional metrics

**Creator & Community Features**
- Dedicated Creator profile page & Creator CTA banner
- Testimonials section with learner feedback

**Course Details & Navigation Pages**
- Course Details with video preview container and tab navigation (About, Lesson, Reviews)
- Interactive footer with multi-column links and newsletter subscription form
